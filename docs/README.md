# 林兆华数字戏剧档案馆 · v3

纯静态 H5/CSS3/JavaScript 网站。

## 内容
- 人物小传与时间线
- 完整作品档案（当前清单版）卡：作者、导演、机构、创作背景、自述、来源
- 高行健合作线、过士行“闲人三部曲”、工作室作品、人艺大型剧场、戏曲与跨界
- 北京大学戏剧研究所专题
- 讲座、工作坊与学术活动
- 中英文双语 UI
- 响应式移动端布局

## 资料原则
历史网站备份与新增公开资料分层；《导演小人书》作为第一人称自述来源，不把其中的主观判断当作外部事实。

## 运行
直接打开 `index.html`。如浏览器限制本地 fetch，可用任意静态 HTTP server 提供目录。


本版作品档案按用户提供的作品清单扩充，并支持多标签筛选；同一作品可同时属于作者谱系与工作室/人艺等标签。


## 编剧/原作字段核验（本轮）
本轮对作品列表中原“其他编剧 / Other playwright(s)”条目逐项核对公开资料，并将列表页改为具体的编剧、原作或改编者；无法严格称为现代“编剧”的经典/戏曲作品，则明确标注“原作”或“改编”。重点核验来源包括中国作家网、北京人民艺术剧院相关资料、中国广播网、国家艺术院团/戏曲资料、当年报刊及作品档案等。

已完成具体姓名替换的条目包括：《为了幸福干杯》《红白喜事》《狗儿爷涅槃》《罗慕洛斯大帝》《三姊妹·等待戈多》《风月无边》《赵氏孤儿》《刺客》《老舍五则》《门客》《伊凡诺夫》《北京有个中关村》《天鹅之歌+论烟草有害》《隆福寺》《一鸟六命》《雷雨2014》《公民》《人民公敌》《夜宴》《狂人日记》《永乐》《张协状元》《杨门女将》，并同步规范《白鹿原》《故事新编》的原作/改编表述。

本轮新增并核验：《谁是强者》（1981）。资料确认林兆华导演、梁秉堃编剧、吕齐/修宗迪/严敏求/李士龙等主演，并补入《人民日报》1981年12月27日第5版评论及1982年全国优秀剧本奖资料。于是之“这小子有点儿歪才”作为导演生平材料线索保留，待进一步找到可公开链接的原始出处后再升级为独立文献引文。
