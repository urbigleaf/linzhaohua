# 林兆华戏剧工作室｜纯静态重构版

这是从旧网站备份转换而来的纯静态网站。

## 特点
- 无 PHP / MySQL / Frame / 服务端脚本
- 响应式移动端布局
- 保留备份中的历史图片
- 将 2006 年演出信息明确标为历史档案
- 新增人物、作品、工作室、研究资料、相关机构、联系等页面
- 新增资料均有公开来源入口，来源列表见 `research.html`
- 旧站问卷/抽奖数据库功能已移除：它依赖当年的 PHP + MySQL 环境，不适合静态站继续运行

## 部署
直接把整个目录上传到任意静态托管即可，例如 Nginx、Apache、GitHub Pages、Cloudflare Pages、Netlify 等。

入口：`index.html`

## 注意
正式公开前，建议再次核验：
1. 旧站文字与图片的版权/授权；
2. 历史联系方式是否需要继续展示；
3. 外部友情链接是否仍为官方域名；
4. 如果要恢复“联系/投稿/问卷”等交互，需要另接表单或无服务器后端。

## 资料原则
旧站原始内容与后续新增内容分开处理。对“1989/1990 年成立”等存在资料差异的事项，保留差异而不强行统一。
